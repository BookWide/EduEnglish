BookWide ERP V1.0 商品主檔（PostgreSQL 唯讀）

1. 覆蓋到 D:\bookwide_erp\erp
2. 先確認 PostgreSQL 8.0 已在 127.0.0.1:5433 啟動
3. 雙擊 START_V1.0_PRODUCT_MASTER.bat
4. 使用 http://127.0.0.1:8787/

功能：
- 真實 PostgreSQL 商品主檔
- 分類樹收合
- 展開後每次載入 100 筆
- 資料庫搜尋
- 點商品顯示主檔
- 產品圖片（Item.photo 有資料時）
- 標籤池、條碼、標籤預覽與列印
- 唯讀，不寫入舊 ERP 資料
